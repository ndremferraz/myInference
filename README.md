# myInference
This is a worklog of my attempt to write my own implementation of an Inference Engine. The idea is to use JAX and TPUs following what can be learned from [How to Scale Your Model](https://jax-ml.github.io/scaling-book/). This worklog style was inspired by [How to Optimize a CUDA Matmul Kernel for cuBLAS-like Performance: a Worklog](https://siboehm.com/articles/22/CUDA-MMM), where the author does a similar thing with a matrix multiplication kernel in CUDA.

This project is divided in Milestones as describes in the [Milestones File](/MILESTONES.md) and I write a small report everytime and milestone is reached.
